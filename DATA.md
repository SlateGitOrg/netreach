# Data

netreach ships no external datasets.

| Data | Location | Source | License |
|---|---|---|---|
| Six fixture topologies (`snapshot.json`) and hand-derived ground truth (`expected.json`) | `testdata/topologies/` | Written by hand for this project | MIT (this repository) |
| Golden report outputs | `internal/cli/testdata/golden/` | Generated by `go test ./internal/cli -update`, reviewed, committed | MIT (this repository) |
| Random topologies for differential tests and benchmarks | generated in memory by `topogen` (deterministic per seed); `netreach gen` writes one to disk | Synthetic | n/a |

Notes:

* All snapshots are **synthetic**. They imitate the shape of AWS VPC
  exports; they are not exports of any real account.
* Internet-side addresses in probes and rules use the RFC 5737 documentation
  ranges (192.0.2.0/24, 198.51.100.0/24, 203.0.113.0/24) or well-known
  examples such as 8.8.8.8 and 93.184.216.34 purely as flow coordinates. The
  "public IPs" assigned to fixture ENIs and NAT gateways (52.x, 54.x) are
  placeholders. No traffic is ever sent anywhere.
* The ground truth in each `expected.json` was derived by hand from the
  rules (each file's `comment` explains the intended trap). One expectation
  was corrected during development; see DECISIONS.md.
